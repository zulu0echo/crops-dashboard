Contribute

Every score on this site comes from a YAML file in the repository. To add a provider or change a score, open a pull request against the repository. The full rules are in CONTRIBUTING.md; the short version:

  1. Copy the reference provider file to data/providers/<slug>.yaml.
  2. List every criterion. Anything you have not evidenced is unknown: true.
  3. Each score needs evidence: a score above 0 needs a verified or documented item, a score above 1 needs a verified item. Repository evidence pins a full commit SHA and file path; onchain evidence names the address and block number.
  4. Run npm run validate, then open the pull request and say which artifact you inspected and how a reviewer re-checks it.

Vendor statements, blog posts, and marketing never raise a score. Evidence that lowers a score is welcome if it is verified, documented, or the provider's own admission; a third party's claim is recorded and can mark a rating disputed, but cannot lower it alone.

Providers

You have a right of reply on every cell through the provider_response field. It is shown beside the score and does not change it. To change the score, add the artifact.
